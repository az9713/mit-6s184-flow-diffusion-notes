# Reader assets

`book.css` and `book.js` implement this edition's offline reader. Chapter SVGs
are computed original teaching figures generated by the corresponding programs.

MathJax is pinned to version 3.2.2, the self-contained `tex-svg.js` distribution:
https://cdn.jsdelivr.net/npm/mathjax@3.2.2/es5/tex-svg.js

Preserved file SHA256:
`d4295dc33744836935c1399feece5159577b34c5c8ffb9f1c6324cd82e03a882`

Its Apache 2.0 license is retained in `mathjax-LICENSE`. No fonts or mathematical
rendering scripts need to be downloaded when reading the bundled book offline.
