4. Conditioning and classifier-free guidance

Lecture 3-B · MIT 6.S184, 2026 · Independent study edition

The recording determines the sequence: conditional generation, classifier guidance, classifier-free algebra, dropout training, and sampling limitations. The Gaussian example and the endpoint counterexample are original teaching constructions. The main written source is Holderrieth and Erives, Section 5, PDF pp. 34–40.

4.1 A correct marginal can answer the wrong request 00:00

A simulator receives a requested operating condition and returns a synthetic measurement. Reproducing the overall distribution of measurements is insufficient: the returned measurement must have the distribution appropriate to that request. A model that ignores the condition can pass an unconditional distribution check while failing this task. Conditioning changes the mathematical target, before any question of strengthening a prompt arises.

Let $Y$ denote the observed condition and $Z\in\mathbb R^d$ a clean data example. Their joint law is the distribution of paired examples used for training. The condition may be a discrete class, a text sequence, or a continuous measurement. Write $p_{\mathrm{data}}(z\mid y)$ for a conditional density when it exists. The target for a fixed allowed request $y$ is this conditional law, rather than the marginal density obtained by averaging over $Y$. Conditional laws are determined almost everywhere in the condition distribution; a fitted model has no automatic guarantee for an unseen or unsupported prompt.

Our running example is scalar. Let $Y$, $E$, and $\varepsilon$ be independent standard normal random variables, and set $Z=Y+E$. Here $E$ is variability in the clean measurement, whereas $\varepsilon$ will supply the initial noise. The conditional distribution is $Z\mid Y=y\sim\mathcal N(y,1)$, while the marginal distribution is $Z\sim\mathcal N(0,2)$. The notation $\mathcal N(m,v)$ means a Gaussian with mean $m$ and variance $v$. These formulas define a continuous version of the conditional law for every real $y$; they do not condition by dividing by the zero probability of the singleton event $Y=y$.

For the request $y=0$, returning an independent $\mathcal N(0,2)$ draw has the correct unconditional law but twice the requested variance. Returning zero every time fixes the mean and removes variability that the task requires. A faithful conditional sampler should instead return $\mathcal N(0,1)$. This example makes conditional correctness measurable without relying on a visual judgment about images.

Use generation time $t\in[0,1]$ and the same independent linear bridge construction used in the earlier chapters, now with this paired data law:

$$X_t=tZ+(1-t)\varepsilon,\qquad V=Z-\varepsilon.$$

The random variable $V$ is the velocity of a coupled bridge sample. At time zero, $X_0=\varepsilon$ has a condition-independent standard normal law. At time one, $X_1=Z$ has the desired data law. Given a request $y$, the bridge has mean $ty$ and variance $c_t=(1-t)^2+t^2$. Without the request, its mean is zero and its variance is $a_t=(1-t)^2+2t^2$. Both variances remain positive on the closed interval. These are new conditional targets for the same bridge mechanism, rather than a redefinition of the earlier chapters' particular endpoint distribution.

4.2 Ordinary conditioning is already a complete mathematical target 01:15

A conditional vector field receives the request as an additional input. Write $u_t(x\mid y)$ for the transport velocity at state $x$ and time $t$ under condition $y$. It is still a vector in the state space, not a velocity of the condition itself. In the bridge above, its population target is the posterior average $\mathbb E[V\mid X_t=x,Y=y]$. The conditional expectation averages clean examples compatible with both the noisy state and the request.

The regression argument can be stated without referring to a particular neural architecture. Let $T$ be a random training time, independent of the data and noise, with a positive density on the time interval being fitted. Let $f(T,X_T,Y)$ be a candidate square-integrable vector predictor. Assume $\mathbb E\|V\|^2$ is finite. Set $U=\mathbb E[V\mid T,X_T,Y]$. Expanding the squared norm around $U$ gives

$$\mathbb E\|f-V\|^2=\mathbb E\|f-U\|^2+\mathbb E\|V-U\|^2.$$

The cross term vanishes because $f-U$ is determined by the conditioning variables and $\mathbb E[V-U\mid T,X_T,Y]=0$. Consequently, the unrestricted population minimizer is $U$ almost everywhere under the training law. Supplying the label to the predictor therefore changes which conditional expectation is learned. It does not change the bridge target $V$ in this construction. Label-dependent bridges are possible, but are a different specified model.

For a Gaussian density with mean $m_t$ and variance $v_t$, the affine field $m'_t+[v'_t/(2v_t)](x-m_t)$ transports that density. To check the claim, solve the centered ODE: its scale factor is $\sqrt{v_t/v_0}$, and its mean follows $m_t$. The resulting Gaussian has precisely the stated mean and variance. Applying this calculation to the running example gives

$$u_t(x\mid y)=y+\frac{2t-1}{c_t}(x-ty),\qquad u_t(x)=\frac{3t-1}{a_t}x.$$

The second field transports the unconditional law. At $t=1/2$, $c_t=1/2$ and $a_t=3/4$. The conditional field is then exactly $y$, whereas the unconditional field is $2x/3$. At state $x=0$ and request $y=1$, the conditional sampler moves right at unit velocity; the unconditional sampler has zero velocity. Merely supplying the label is enough to define the correct ideal conditional transport.

Finite data, restricted model classes, imperfect optimization, and numerical integration can prevent a learned sampler from attaining that ideal. Mispaired training examples can also make the learned conditional law differ from the user's intended meaning. Those mechanisms should be diagnosed separately. The existence of a useful stronger-guidance heuristic does not show that exact conditional generation is mathematically defective. The course's paired regression objective is given in Section 5.1, Eqs. (57)–(58).

4.3 Bayes' rule identifies the condition-dependent score 08:36

To strengthen a request, first identify the part of the field that depends on it. Let $p_t(x)$ be the unconditional state density, $p_t(x\mid y)$ its conditional density, and $r_t(y\mid x)$ the conditional probability mass or density of the request given the noisy state. The last object is a classifier when $Y$ is discrete. Its time dependence matters: the same clean example looks different at different noise levels.

Fix a time and a condition in a region where the relevant densities are positive and differentiable in $x$. Bayes' rule reads $p_t(x\mid y)=p_t(x)r_t(y\mid x)/p_Y(y)$, where $p_Y(y)$ is the condition's mass or density under the paired data law. Define the spatial scores $s_t(x)=\nabla_x\log p_t(x)$ and $s_t^y(x)=\nabla_x\log p_t(x\mid y)$. Taking a logarithm and differentiating with respect to $x$ eliminates $\log p_Y(y)$, because it is constant in that variable:

Proposition 4.1 — Conditional score decomposition. Under the stated positivity and differentiability assumptions,

$$s_t^y(x)=s_t(x)+\nabla_x\log r_t(y\mid x).$$

The logarithm of a product is the sum of its logarithms. Thus $\log p_t(x\mid y)=\log p_t(x)+\log r_t(y\mid x)-\log p_Y(y)$. Differentiate each term in $x$. The final term has zero derivative, which proves the identity. Normalizing the conditional law remains necessary, even though that normalization disappears from its spatial score. ∎

For the scalar Gaussian example, the conditional score is $-(x-ty)/c_t$, and the unconditional score is $-x/a_t$. Their difference is $ty/c_t-t^2x/(a_tc_t)$. This also follows by differentiating the Gaussian posterior $Y\mid X_t=x$, whose mean is $tx/a_t$ and variance is $c_t/a_t$. The agreement checks that the derivative is taken with respect to the noisy state, not the request or the network parameters.

A score decomposition becomes a velocity decomposition only when the score-to-velocity relation has been specified. For a general Gaussian bridge $X_t=\alpha_t Z+\beta_t\varepsilon$, let $\alpha_t$ and $\beta_t$ be differentiable scalar schedules, with both nonzero at the time considered. The noise is independent standard Gaussian and independent of the paired data. Assume the conditional Gaussian mixture may be differentiated under its integral and that its posterior first moments are finite. Differentiating the bridge sample gives $V_t=\dot\alpha_t Z+\dot\beta_t\varepsilon$, where a dot denotes a time derivative. Conditional-score marginalization gives $s_t^y=-(x-\alpha_t\mathbb E[Z\mid X_t=x,Y=y])/\beta_t^2$. Solve this identity for the posterior mean, and substitute $\varepsilon=(x-\alpha_t Z)/\beta_t$ into $V_t$. Averaging produces

$$u_t(x\mid y)=B_t x+A_t s_t^y(x),\qquad B_t=\frac{\dot\alpha_t}{\alpha_t},\qquad A_t=\beta_t^2\frac{\dot\alpha_t}{\alpha_t}-\beta_t\dot\beta_t.$$

The same coefficients relate $u_t(x)$ to $s_t(x)$. Therefore $u_t(x\mid y)-u_t(x)=A_t\nabla_x\log r_t(y\mid x)$. The coefficient $A_t$ is fixed by the chosen probability path; it is not an arbitrary classifier step size. For the linear bridge, $A_t=(1-t)/t$ and $B_t=1/t$ at $0\lt t\lt1$. Individual terms are singular at time zero even though the Gaussian velocities derived directly in Section 4.2 extend continuously there.

Classifier guidance replaces the conditional field by $u_t(x)+wA_t\nabla_x\log r_t(y\mid x)$ for a chosen total scale $w$. The value $w=1$ recovers ordinary conditional transport. Choosing $w\gt1$ amplifies the classifier contribution. A separately trained classifier must estimate the noisy-state posterior at the appropriate time. Substituting an ordinary clean-image classifier has no guarantee of supplying that posterior or its gradient. The course derives this construction in PDF pp. 36–37, Eqs. (59)–(62).

4.4 Remove the explicit classifier by subtracting two fields 19:49

The classifier term can be recovered from two generative fields. Substituting $A_t\nabla_x\log r_t(y\mid x)=u_t(x\mid y)-u_t(x)$ into the guidance rule gives

$$u_t^{(w)}(x\mid y)=u_t(x)+w\bigl(u_t(x\mid y)-u_t(x)\bigr)=(1-w)u_t(x)+w u_t(x\mid y).$$

This is the classifier-free guidance, or CFG, construction. It removes a separate classifier from the expression. It does not remove conditioning, nor does it remove the unconditional branch. At $w=0$, the field is unconditional. At $w=1$, it is ordinarily conditional. For $w\gt1$, the coefficient of the unconditional branch is negative: the rule extrapolates along the difference between fields, rather than taking a convex average. At $t=1/2$, $x=0$, and $y=1$ in our example, total scale two changes the velocity from one to two.

One network can represent both branches by accepting an additional null condition, written $\varnothing$, that is distinct from every genuine request. Write its output as $u_t^\theta(x\mid y)$, where $\theta$ denotes the learned parameters, and identify $u_t^\theta(x\mid\varnothing)$ as the unconditional prediction. The sampled field is then $(1-w)u_t^\theta(x\mid\varnothing)+wu_t^\theta(x\mid y)$. Two evaluations of shared parameters replace the separate classifier. A null condition must be trained; an arbitrary empty string is not guaranteed to implement it.

Scale conventions differ between sources. Ho and Salimans, Eq. (6) and Algorithm 2, combine noise predictions as $(1+\omega)\varepsilon_\theta(x\mid y)-\omega\varepsilon_\theta(x\mid\varnothing)$. Their symbol $\omega$ here denotes an extra guidance amount, translated from the paper's own notation. Our total scale is $w=1+\omega$. Thus their zero means ordinary conditional sampling, while our zero means unconditional sampling. The numbers cannot be transferred between implementations until this convention and the predicted quantity have been checked.

For a common Gaussian bridge with $\beta_t\ne0$, the noise prediction and score satisfy $\varepsilon_\theta=-\beta_t s_\theta$. Multiplication by this common scalar commutes with the guidance combination. The affine velocity relation also commutes because its coefficients sum to one. These facts justify translating the same algebra among consistently parameterized predictors. They do not justify mixing predictions from different schedules, latent normalizations, or noise levels.

Approximation errors can also be extrapolated. Let $e_{\varnothing}$ and $e_y$ be the errors of the null and conditional fields at the same time and state. The combined error is $e_w=(1-w)e_{\varnothing}+we_y$. The triangle inequality gives $\|e_w\|\le|1-w|\|e_{\varnothing}\|+|w|\|e_y\|$. For $w\ge1$ and separate bounds of size $\delta$, the worst-case bound is $(2w-1)\delta$. Errors pointing in opposite directions attain it; identical branch errors merely pass through unchanged. A larger scale can therefore amplify uncertainty, but its actual effect depends on error correlation and the states visited by the altered sampler.

4.5 Independent condition dropout learns the null branch 30:36

The paired dataset contains genuine conditions, rather than examples labeled “unconditional.” Training creates such examples deliberately. Let $D$ be a Bernoulli random variable: $D=1$ with probability $\eta$ and $D=0$ otherwise, where $0\lt\eta\lt1$. Choose $D$ independently of the paired data, training time, and bridge noise. Define the training input condition $\widetilde Y$ to equal $\varnothing$ when $D=1$ and to equal $Y$ otherwise. The clean example and regression target are retained even when its label is hidden.

Proposition 4.2 — Population targets of condition dropout. Under the finite second-moment assumptions of Section 4.2, the unrestricted squared-error minimizer predicts $\mathbb E[V\mid T,X_T,Y]$ on genuine conditions and $\mathbb E[V\mid T,X_T]$ on the null condition, almost everywhere under the corresponding training laws.

Squared-error projection onto the information $(T,X_T,\widetilde Y)$ gives the minimizer $\mathbb E[V\mid T,X_T,\widetilde Y]$. On a retained example, the input reveals $Y$ and $D=0$. Independence of $D$ makes this last observation irrelevant to the conditional distribution of $V$. On a dropped example, the input reveals only $T,X_T$ and $D=1$; independence again removes $D$. The two conditional expectations are therefore exactly those stated. The restrictions on $\eta$ ensure that both kinds of examples have positive probability. ∎

Equivalently, the population loss of a shared predictor is the weighted sum $(1-\eta)L_{\mathrm{conditional}}(\theta)+\eta L_{\mathrm{null}}(\theta)$. An unrestricted function can attain both branch targets. A finite shared network may face a capacity tradeoff, so changing $\eta$ can change its best approximation. The projection argument establishes the desired targets; it does not establish successful optimization or a universal optimal dropout rate. At $\eta=0$, the null branch is unconstrained by this loss. At $\eta=1$, the genuine-condition branch is unconstrained.

Independence is a substantive requirement. Consider equally likely labels zero and one with clean measurements minus one and plus one. If the zero label is dropped with probability $0.9$ but the one label with probability $0.1$, the null subset has mean $-0.8$ rather than the unconditional mean zero. Indeed, its two unnormalized weights are $0.5(0.9)$ and $0.5(0.1)$; normalization gives probabilities $0.9$ and $0.1$. A null regressor trained on that subset learns a selected distribution. It is not an unconditional model of the original paired data. Independent dropout avoids this selection effect.

The original CFG algorithm uses random conditioning removal in a shared model; see Ho and Salimans, Algorithm 1. The course translates the mechanism to conditional flow matching in Algorithm 5 and Eqs. (63)–(65). Our synthetic example analyzes the population mechanism without training an image model. Its linear bridge has $V=Z-\varepsilon$ with finite variance, so the finite-risk projection assumptions hold for the stated Gaussian data.

4.6 A mixed score is not an endpoint sampling theorem 33:27

Sampling fixes a request $y$, draws $X_0$ from the initial law, and integrates the altered field $u_t^{(w)}(X_t\mid y)$. At total scale one, exact conditional transport gives the specified conditional endpoint, under its well-posedness assumptions. At other scales, the field has changed. A useful interpretation of its score is available, but that interpretation must not be promoted into an unproved statement about the sampler's terminal distribution.

For a fixed time, suppose the positive densities yield a finite normalizing integral $C_t=\int p_t(x\mid y)^w p_t(x)^{1-w}\,dx$. Define the normalized density $q_t(x)=p_t(x\mid y)^wp_t(x)^{1-w}/C_t$. Because $C_t$ does not depend on $x$, differentiation gives $\nabla_x\log q_t=ws_t^y+(1-w)s_t$. This is a fixed-time identity. It says nothing yet about $\partial_tq_t$, which must satisfy the continuity equation of a proposed flow if that flow is to realize the whole family.

The distinction can be checked exactly in the running example. Take the request $y=0$. Its conditional density is centered Gaussian with variance $c_t$, and its unconditional density is centered Gaussian with variance $a_t$. The mixed score is $-K_tx$, with $K_t=w/c_t+(1-w)/a_t$. Whenever $K_t\gt0$, the normalized tilt is Gaussian with variance $1/K_t$. For $w\ge1$, positivity follows from $a_t\ge c_t$: $K_t=1/a_t+w(1/c_t-1/a_t)\gt0$.

Proposition 4.3 — An exact CFG endpoint need not equal the normalized tilt. In the Gaussian construction, the exact guided ODE started from $\mathcal N(0,1)$ has variance $V_t=c_t^w a_t^{1-w}$. At $w=2$ and time one, its variance is $1/2$, whereas the normalized fixed-time tilt has variance $2/3$.

The conditional and unconditional velocities for request zero are respectively $c'_tx/(2c_t)$ and $a'_tx/(2a_t)$. Their CFG combination is $k_tx$, where $k_t=wc'_t/(2c_t)+(1-w)a'_t/(2a_t)$. The solution of this scalar linear ODE multiplies the initial draw by $\exp(\int_0^t k_s\,ds)$, so its variance satisfies $V'_t=2k_tV_t$ and $V_0=1$. Integrating the logarithmic derivative gives

$$\log V_t=w\log c_t+(1-w)\log a_t,\qquad V_t=c_t^wa_t^{1-w},$$

because $c_0=a_0=1$. At time one, $c_1=1$ and $a_1=2$. For scale two, the ODE variance is therefore $1^2/2=1/2$. The tilted density instead has precision $2/1-1/2=3/2$, hence variance $2/3$. All relevant variances and coefficients are finite and positive; this disagreement comes from temporal consistency, not a singular endpoint or a poor learned model. ∎

Both families start from the same standard normal density. Both conditional and unconditional fields are exact. Nevertheless, combining their scores at each time does not make the guided ODE follow the corresponding normalized tilt. Ordinary conditional sampling, $w=1$, is recovered by both formulas. The counterexample concerns the specified deterministic flow; it does not assign one universal endpoint law to every guided SDE, discrete sampler, or learned diffusion model.

For a centered Gaussian, the compatibility condition is especially visible. If its proposed variance is $q_t^{\mathrm{var}}=1/K_t$, a linear velocity $k_tx$ transports it only if $(q_t^{\mathrm{var}})'=2k_tq_t^{\mathrm{var}}$. The fixed-time score formula alone does not impose that derivative identity. This is the missing step in an argument that treats an instantaneous score mixture as a complete sampling theorem.

The same distinction matters when adding stochastic noise. A drift correction derived for a compatible velocity, score, and density path need not remain compatible after separate guidance mixtures. For example, combine the exact branch drifts with a common constant diffusion amplitude $\sigma$. The mixed drift is $(k_t-\sigma^2K_t/2)x$. To compute its effect, consider a continuous deterministic coefficient $\ell_t$ and $dX_t=\ell_tX_t\,dt+\sigma\,dW_t$, with an independent standard normal initial state. Set $\Phi_t=\exp(\int_0^t\ell_s\,ds)$. The deterministic integrating-factor argument gives

$$X_t=\Phi_t\left(X_0+\sigma\int_0^t\Phi_s^{-1}\,dW_s\right),\qquad V_t=\Phi_t^2\left(1+\sigma^2\int_0^t\Phi_s^{-2}\,ds\right).$$

The variance formula uses independence of the initial state and the stochastic integral. Differentiate it using $\Phi'_t=\ell_t\Phi_t$ to obtain $V'_t=2\ell_tV_t+\sigma^2$. With $\ell_t=k_t-\sigma^2K_t/2$, this is $(2k_t-\sigma^2K_t)V_t+\sigma^2$, while the guided ODE has derivative $2k_tV_t$. They agree along a common variance path only when $\sigma^2(1-K_tV_t)=0$. At time one in the scale-two construction, $K_tV_t=3/4$, which violates this condition for nonzero $\sigma$. Thus one-time marginal equivalence must be re-established for the altered construction; the unguided equivalence theorem cannot be reused unchanged.

4.7 Separate the guidance rule from numerical solver error

The counterexample is exact, but a finite-step sampler introduces another discrepancy. For request zero, apply $N$ explicit Euler updates with step $h=1/N$ and times $t_n=n/N$. The scalar update multiplies each state by $1+hk_{t_n}$. Starting from variance one, the exact variance of this discrete sampler is therefore the product $\prod_{n=0}^{N-1}(1+hk_{t_n})^2$. It can be computed without Monte Carlo error. Refining the grid should approach the guided ODE variance, not the normalized tilt variance.

The following standalone calculation checks the two exact endpoint expressions. It accepts no external inputs, uses only the standard library, reads and writes no files, and makes no network calls. It performs no learning. Its purpose is to compare the implications of the declared mathematical models.

scale = 2
conditional_variance = 1.0
marginal_variance = 2.0
ode_variance = conditional_variance**scale * marginal_variance**(1-scale)
tilt_precision = scale/conditional_variance + (1-scale)/marginal_variance
print(f"ODE variance: {ode_variance:.6f}")
print(f"Tilt variance: {1/tilt_precision:.6f}")
assert abs(ode_variance - 0.5) < 1e-12
ODE variance: 0.500000
Tilt variance: 0.666667

The complete chapter program evaluates the Euler products and checks the derivative of the exact variance independently by centered differences. Its default run prints results without writing files; the explicit --write option regenerates the results JSON and computed density figure in this book. It rejects nonpositive or noninteger step counts. The saved actual results give scale-two Euler variances $0.478395$ at 64 steps and $0.498622$ at 1,024 steps. Both approach $0.5$. Solver refinement cannot close the persistent gap between $0.5$ and $2/3$.

Ordinary CFG evaluates a shared model on the conditional and null inputs at each field evaluation. For a solver requiring $M$ field evaluations, this amounts to $2M$ branch evaluations rather than $M$, if both branches are computed afresh each time. The evaluations can be batched, and other pipeline work may be shared. Consequently, twice the branch count does not imply twice the elapsed time, twice the parameter memory, or half the throughput on every machine. A cost claim must state its accounting unit and implementation assumptions.

At exactly $w=1$, the null coefficient vanishes, so computing the unused branch is unnecessary. At $w=0$, the conditional branch is unused. At other scales, suppressing one branch changes the defined field unless some additional approximation supplies it. This is a concrete engineering consequence of the algebra, rather than a claim that every production implementation uses the same call pattern.

4.8 What guidance establishes, and what it changes

Three statements now have different evidentiary status. Bayes' score decomposition and the independent-dropout population targets are mathematical identities under stated assumptions. The Gaussian endpoint disagreement is a proved counterexample for a specific exact flow. Improvements in perceived prompt adherence for learned image models are empirical claims, whose validity depends on the data, model, sampler, guidance scale, and evaluation procedure. One category cannot substitute for another.

Ho and Salimans, Section 4, study guidance-strength tradeoffs on particular class-conditional ImageNet diffusion models. Those historical experiments motivate the mechanism; they do not certify an optimal scale for a new model or prove that every generated image uses CFG. No image benchmark has been reproduced in this chapter. The course's third laboratory provides a separate practical route through conditional image generation, with dependencies and training costs beyond the scalar checks here.

Learned “scores” also need qualification. A generic vector-valued neural predictor is not constrained to be the gradient of a scalar potential. Thus its linear combination need not equal the score of any normalized density. The exact-density interpretation above applies when true scores or suitable conservative fields are available. Ho and Salimans, Section 3.2, explicitly distinguish exact score algebra from unconstrained learned predictions. Their shared-model training is a practical way to supply the branches, not a theorem that finite learned fields satisfy every density identity.

The simulator can now distinguish three goals: reproduce the unconditional measurement law, reproduce the law appropriate to a request, and deliberately alter that conditional behavior by extrapolating a guidance difference. Testing should identify which goal is intended. Even a perfectly measured improvement in request adherence would not imply unchanged diversity, calibrated uncertainty, faithful conditional probabilities, or numerical equivalence between different samplers.

4.9 Problems with worked solutions

Problem 4.1 — Derive the noisy-condition posterior

In the Gaussian construction, derive the distribution of $Y\mid X_t=x$ for fixed $t$. Differentiate its log density with respect to $x$, and verify the Bayes score decomposition. Explain why a classifier trained only at the clean endpoint would generally supply the wrong noisy-state posterior.

Solution 4.1

The prior density of $Y$ is proportional to $\exp(-y^2/2)$, and the likelihood of $x$ given $y$ is proportional to $\exp(-(x-ty)^2/(2c_t))$. Their product has exponent $-[y^2+(x-ty)^2/c_t]/2$. Completing the square in $y$ gives posterior precision $1+t^2/c_t=a_t/c_t$ and mean $tx/a_t$. Hence the posterior is $\mathcal N(tx/a_t,c_t/a_t)$.

Only the posterior mean depends on $x$. Differentiation therefore gives

$$\partial_x\log r_t(y\mid x)=\frac{t}{c_t}\left(y-\frac{tx}{a_t}\right).$$

Meanwhile, $s_t^y-s_t=-(x-ty)/c_t+x/a_t$. Since $a_t-c_t=t^2$, this equals the same expression. The posterior varies with $t$. At time zero it is the prior because $X_0$ is independent noise; at time one it has mean $x/2$ and variance $1/2$. A clean-only classifier represents the latter observation model, not every intermediate one.

Problem 4.2 — Translate scales and expose an error bound

An implementation uses the paper convention $(1+\omega)f_y-\omega f_{\varnothing}$ with $\omega=3$. What is the total scale? If each branch error has norm at most $\delta$, find the worst-case combined bound, an example attaining it, and an example for which the error is not amplified.

Solution 4.2

The total scale is $w=1+3=4$. The combined error is $4e_y-3e_{\varnothing}$, whose norm is at most $7\delta$. Choose a unit vector $v$ and errors $e_y=\delta v$, $e_{\varnothing}=-\delta v$; the error is then $7\delta v$, so the bound is attained. If both errors instead equal $\delta v$, their combination is just $\delta v$. The bound describes worst-case alignment, not the typical error correlation of a shared trained network.

Problem 4.3 — Diagnose selected dropout

Use the equally likely two-label example in Section 4.5. Verify the null-subset probabilities and mean under label-dependent dropout. What condition on the two dropout probabilities would recover the original label proportions, assuming both are positive?

Solution 4.3

The probability of a dropped zero-label example is $0.5\times0.9=0.45$ and that of a dropped one-label example is $0.5\times0.1=0.05$. The total dropped probability is $0.5$, so the conditional proportions are $0.9$ and $0.1$. Their clean-data mean is $0.9(-1)+0.1(1)=-0.8$.

For positive dropout probabilities $\eta_0,\eta_1$, the retained null-subset proportions are $\eta_0/(\eta_0+\eta_1)$ and $\eta_1/(\eta_0+\eta_1)$. Both equal one half exactly when $\eta_0=\eta_1$. Equality removes this label-selection effect. Full independence from time, state, and noise remains the stronger condition used in Proposition 4.2.

Problem 4.4 — Separate two endpoint laws

For request zero, derive the guided ODE variance and the normalized tilt variance at time one for arbitrary total scale $w\ge1$. Evaluate both at $w=4$. Explain why taking more Euler steps cannot make the two limits agree at that scale.

Solution 4.4

At time one the conditional variance is one and the unconditional variance is two. Proposition 4.3 gives ODE variance $2^{1-w}$. The tilted precision is $w+(1-w)/2=(1+w)/2$, so its variance is $2/(1+w)$. At total scale four, these are $1/8=0.125$ and $2/5=0.4$, respectively.

Euler refinement converges to the solution of the specified guided ODE under its smooth bounded coefficients on the finite interval. It reduces numerical error relative to $2^{1-w}$; it does not change the differential equation into one transporting the normalized tilt. For $w\gt1$, the two formulas differ: writing $r=w-1\gt0$, equality would require $2^r=1+r/2$, while convexity of $2^r$ gives $2^r\ge1+r\log2\gt1+r/2$.

Problem 4.5 — Test stochastic compatibility

Assume a nonzero constant diffusion amplitude and mix the exact conditional and null stochastic drifts with total scale two. Could this SDE have the guided ODE's entire Gaussian variance path in Proposition 4.3? Compute the extra variance-derivative term at time one when $\sigma=1$.

Solution 4.5

A scalar linear SDE $dX_t=\ell_tX_t\,dt+\sigma\,dW_t$ has variance derivative $V'_t=2\ell_tV_t+\sigma^2$. This follows from the explicit integrating-factor solution and the deterministic-integrand variance rule. For the mixed branch drift, $\ell_t=k_t-\sigma^2K_t/2$, giving $V'_t=2k_tV_t+\sigma^2(1-K_tV_t)$.

At time one, the proposed ODE variance is $1/2$ and $K_t=3/2$. The extra term is $1-(3/2)(1/2)=1/4$. It is nonzero, so the two variance equations cannot describe the same whole path. This argument does not claim that every different pair of variance equations must have different values at every isolated time; it refutes equality of the entire proposed family.

Problem 4.6 — Compare implementations using explicit cost units

A solver uses 40 field evaluations. Each ordinary conditional branch evaluation takes an assumed 5 milliseconds, and other work costs an assumed 20 milliseconds per generated batch. Estimate elapsed time for ordinary conditioning and for two-branch CFG if branch work is sequential and costs add. What changes if batching two branches costs an assumed 7 milliseconds? State which counts remain exact within this model.

Solution 4.6

Ordinary conditioning costs $40(5)+20=220$ milliseconds. Sequential two-branch CFG costs $40(10)+20=420$ milliseconds, a ratio $420/220\approx1.909$, rather than exactly two. With the assumed batched cost it costs $40(7)+20=300$ milliseconds, a ratio $300/220\approx1.364$.

The branch-evaluation counts are 40 and 80 for implementations that evaluate the specified branches afresh. The number of parameter sets remains one for a shared model. The timings are stipulated arithmetic examples, not hardware measurements. Actual batching efficiency, solver adaptivity, embeddings, decoding, and memory traffic would need measurement. At total scale one, the unused null branch can be omitted.
